# SoilBoard KiCad project

Open `SoilBoard.kicad_pro` in KiCad to access the schematic and PCB layout.

## Included files

- `SoilBoard.kicad_pro`: KiCad project settings.
- `SoilBoard.kicad_sch`: editable schematic.
- `SoilBoard.kicad_pcb`: editable PCB layout.
- `fp-lib-table`: footprint-library mapping used by the project.

## Import cleanup

The supplied archive contained a nested Git repository, editor lock files,
local KiCad state, an additional zipped PCB, and 171 automatic backup ZIPs.
Those generated and historical artifacts were intentionally excluded. The four
canonical editable project files above are retained in this repository.
